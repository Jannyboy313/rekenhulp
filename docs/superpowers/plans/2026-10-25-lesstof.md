# Lesstof framework — plan

Spec: `docs/superpowers/specs/2026-10-25-lesstof-design.md` §3–§6; entry points in the main spec
§3, §3.1, §3.2. TDD, one commit per task. Scope: the framework only. `LESSONS` stays empty; the
Tafels content is a separate session (lesstof spec §2, §7).

## Decisions

- Content is typed data in `lib/lessons/`, rendered with `MathText`. No markdown, no dependency.
- `LESSONS` is empty after this plan. The Lesstof tab is visible and shows an empty list, no
  placeholder text.
- Testability without content: `lessonFor` and `App.svelte` take the lessons as an argument/prop
  with `LESSONS` as default, so tests pass a fixture lesson.
- Not doing: read marks, search, next/previous, lessons during play, images, bullet lists.

type LessonBlock =
  | { type: 'text'; text: string }

// index.ts

## Task 2 — content checks (`lib/lessons/validate.ts`)

Files: `lib/lessons/validate.ts`, `lib/lessons/validate.test.ts`

- `chainHolds(line: string): boolean`: split on ` = `, `parse` (`lib/expr/parser`) every side,
  `evaluate`, compare with `equals` (`lib/rational`). `false` for fewer than two sides or an
  unparsable side.
- `lessonProblems(lessons): string[]`: structure — `setId` not in `PRACTICE_SETS`, duplicate
  topic id within a lesson, zero topics, a topic without blocks. Readable messages.
- `textProblems(lesson): string[]`: ASCII operators (`*`, ` x `, `/` used as division, i.e. not a
  fraction `a/b` as defined by `splitFractions`), a literal `?` in a `worked` line, and every
  `worked` line for which `chainHolds` is false.
- A test runs both over `LESSONS` (now trivially `[]`) and the fixture, expecting `[]`.

| Input `lessonProblems` | Expected |
| --- | --- |
| `[FIXTURE]` | `[]` |
| unknown `setId` / duplicate topic id / zero topics / topic without blocks | 1 problem each |

| Input `chainHolds` | Expected |
| --- | --- |
| `13 × 7 = 10 × 7 + 3 × 7 = 70 + 21 = 91` | true |
| `84 : 6 = 60 : 6 + 24 : 6 = 14` | true |
| `100 − 10 − 5 = 85` (left to right) | true |
| `3/4 = 6/8` | true |
| `13 × 7 = 90` | false |
| `13 × 7` | false |
| `13 × = 91` | false |

| Input `textProblems` (one block) | Expected |
| --- | --- |
| text `7 * 8` | 1 problem |
| text `7 x 8` | 1 problem |
| text `3/4 deel` | none (fraction) |
| worked `7 × ? = 56` | 1 problem |
| worked `13 × 7 = 90` | 1 problem |

## Task 5 — wiring, back guard, setup button (`App.svelte`, `SetupScreen.svelte`)

- `App` prop `lessons = LESSONS` (main.ts unchanged). `Screen` gains
  `{ name: 'lessonTopics'; set; lesson; from: 'sets' | 'setup' }` and
  `{ name: 'lesson'; set; lesson; topic; from }`. `tab` is `$state` in `App`.
- `SetupScreen` gets optional `onlesson`; the **Lesstof** button (secondary, above Start)
  renders only when it is passed. App passes it when `lessonFor(set, lessons)` exists.
- Back guard: after a `popstate` that lands on a screen other than `sets`, call
  `backGuard.arm()` (the `$effect` does not re-run between two non-`sets` screens). Terug on
  `lessonTopics`: `from === 'setup'` → `{ name: 'setup', set }`, else `sets` (tab unchanged).
