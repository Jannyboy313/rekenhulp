# Lesstof framework — plan

Spec: `docs/superpowers/specs/2026-10-25-lesstof-design.md` §3–§6; entry point in the main spec
§3, §3.1. TDD, one commit per task. Scope: the framework only. `LESSONS` stays empty; the Tafels
content is a separate session (lesstof spec §2, §7).

## Decisions

- Content is typed data in `lib/lessons/`, rendered with `MathText`. No markdown, no dependency.
- The Lesstof tab lists all sets; a set without a lesson is a disabled row (global
  `button:disabled` dimming, no new styles). After this plan every row is disabled.
- Separation (lesstof spec §4): lesson components are their own; practice components
  (`SetupScreen`, `PlayScreen`, `ResultScreen`, …) are not touched. Shared only: the overview
  shell and the presentational `SetRow`.
- Linking: `lessonTopics` carries a `returnTo: Screen`; `openLesson(set, lesson, returnTo)` in
  `App.svelte` is the single way in. Only the Lesstof tab calls it now.
- Testability without content: `lessonFor` and `App.svelte` take the lessons as argument/prop
  with `LESSONS` as default, so tests pass a fixture lesson.
- Not doing: setup-screen link, read marks, search, next/previous, images, bullet lists.

## Task 2 — content checks (`lib/lessons/validate.ts`)

Files: `lib/lessons/validate.ts`, `lib/lessons/validate.test.ts`

- `chainHolds(line: string): boolean`: split on ` = `, `parse` (`lib/expr/parser`) every side,
  `evaluate`, compare with `equals` (`lib/rational`). `false` for fewer than two sides or an
  unparsable side.
- `lessonProblems(lessons): string[]`: `setId` not in `PRACTICE_SETS`, duplicate topic id within
  a lesson, zero topics, a topic without blocks.
- `textProblems(lesson): string[]`: ASCII operators (`*`, ` x `, `/` that is not a fraction as
  `splitFractions` reads it), a literal `?` in a `worked` line, every `worked` line for which
  `chainHolds` is false.
- A test runs both over `LESSONS` (now trivially `[]`) and the fixture, expecting `[]`.

| Input `chainHolds` | Expected |
| --- | --- |
| `13 × 7 = 10 × 7 + 3 × 7 = 70 + 21 = 91` | true |
| `84 : 6 = 60 : 6 + 24 : 6 = 14` | true |
| `100 − 10 − 5 = 85` (left to right) | true |
| `3/4 = 6/8` | true |
| `13 × 7 = 90` | false |
| `13 × 7` | false |
| `13 × = 91` | false |

| Input | Expected |
| --- | --- |
| `lessonProblems([FIXTURE])` | `[]` |
| unknown `setId` / duplicate topic id / zero topics / topic without blocks | 1 problem each |
| text `7 * 8` / text `7 x 8` | 1 problem |
| text `3/4 deel` | none (fraction) |
| worked `7 × ? = 56` / worked `13 × 7 = 90` | 1 problem |

## Task 6 — wiring and back guard (`App.svelte`)

```ts
type LessonTopicsScreen = { name: 'lessonTopics'; set: PracticeSet; lesson: Lesson; returnTo: Screen };
type Screen = /* existing */ | LessonTopicsScreen | { name: 'lesson'; parent: LessonTopicsScreen; topic: LessonTopic };
function openLesson(set: PracticeSet, lesson: Lesson, returnTo: Screen): void;
```

- `App` prop `lessons = LESSONS` (`main.ts` unchanged). `LessonSetList.onopen` →
  `openLesson(set, lesson, { name: 'sets' })`.
- Terug: `lesson` → `parent`; `lessonTopics` → `returnTo` (tab state unchanged).
- Back guard: `handlePopState` maps a system back on a lesson screen to the same Terug, then calls
  `backGuard.arm()` when the new screen is not `sets` (the `$effect` does not re-run between two
  non-`sets` screens).
- No changes to `SetupScreen`, `PlayScreen`, `ResultScreen`.
