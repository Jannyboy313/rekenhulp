> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to
> implement this plan task by task. This is a light plan: per task the files, signatures, test
> cases and tips. Write the code yourself, TDD, one commit per task.

**Goal:** Add the topic `speed` (spec §5.26) to the existing **Meten** set. The set grows from 6
to 7 topics with weight 1 and gets the description "Eenheden, grote getallen en snelheid".

**Spec:** `docs/superpowers/specs/2026-10-05-rekenhulp-design.md`. Read §3.4.1 (the tip rules and
the `time` and `speed` rows: they are the source of truth for tip wording), §4.1–§4.2, §5.10
(time conversion and `timeTip`), §5.26, §6 and §8.

**Architecture:** one new generator module `src/lib/topics/speed.ts`, following the pattern of
`scale.ts`: a pure `(rng) => Question`, answers checked by `numberStep`, tips as `Diagnose`
functions. No component, keypad or `lib/expr` changes: the unit suffix already works. The
conversion engine of §5.10 is not extended (factor 3,6); only `HOUR` and `MINUTE` are exported
from `measurement.ts` to reuse `timeTip`.

## Notes for the implementer

- **Characters:** write U+202F (thousands separator) and U+2212 (minus) in code and tests as
  `'\u{202f}'` and `'\u{2212}'` (or `GROUP_SEPARATOR`, `MINUS` from `format.ts`). Never paste the
  raw characters. Numbers stay below 10 000 here, so grouping does not occur in prompts.
- **Number formatting:** `formatRational` (decimal comma), `formatInteger`, `formatFraction`
  (`3/4`, for the minutes-as-hours tip; `rational(45n, 60n)` normalises to 3/4).
- **Fraction text pitfall (§8):** never put a number, a space and a fraction side by side unless
  it is a mixed number. `45 min is 3/4 uur` is fine (`is` sits between them).
- **`noUncheckedIndexedAccess`:** do not destructure a ternary of array literals; write two
  ternaries.
- **Generators are pure:** every random choice goes through `rng`; use `pick` and `randomInt`
  from `random.ts`. Candidate lists are computed once at module load and picked from, as in
  `scale.ts` (`MAP_DISTANCES_BY_SCALE`).
- **Tips** fire only when the answer equals exactly what the mistake produces. Build tip text
  lazily, inside the `Diagnose` after the equality check: values such as 25 min in hours
  (5/12) are not finite decimals and `formatRational` must not be called on them.
- **Factor-of-ten fallback** is applied by `numberStep` itself; do not add it.
- **Every generator test** has, besides the case tables below, a seeded invariant test (1000
  questions, `createRng(<fixed seed>)`): ranges per form and context, `check(expected)` is
  correct, and each form and context occurs. Statistical assertions use wide margins; if one
  fails narrowly, report it instead of tuning to the seed.
- **Prompts** in this plan are exact.

## Task 1: `speed` part 1 — contexts, speed and distance

**Files:** `src/lib/types.ts`, `src/lib/topics/speed.ts`, `src/lib/topics/speed.test.ts`,
`src/lib/topics/index.ts`

`types.ts`: add `'speed'` to `Topic`. `index.ts`: register `generateSpeed` and the label
`'Snelheid (afstand, tijd, km/u en m/s)'`. In this task `generateSpeed` draws only the forms

**Signatures:**

```ts
export type SpeedContext = 'wandelen' | 'fietsen' | 'auto' | 'trein';
export const CONTEXTS: readonly SpeedContext[];

/** Speeds in km/u and the largest distance in km per context (spec §5.26). */
export const CONTEXT_SPEEDS: Readonly<Record<SpeedContext, readonly number[]>>;
export const MAX_DISTANCE: Readonly<Record<SpeedContext, number>>;

/** A time as shown: 45 min or 2,5 uur. */
export interface Duration {
  amount: Rational;
  unit: 'min' | 'uur';
}
/** {10, 12, 15, 20, 30, 40, 45} min and {1,5; 2; 2,5; 3; 4} uur. */
export const PROMPT_DURATIONS: readonly Duration[];
export function hoursOf(duration: Duration): Rational;

export interface Trip {
  context: SpeedContext;
  speed: number; // km/u
  duration: Duration;
  distance: Rational; // km
}

export type TravelForm = 'speed' | 'distance';

/**
 * Trips with a prompt duration whose ratio table has at most 1 decimal everywhere, distance in
 * [0,5; MAX_DISTANCE]. The same candidates serve the speed and the distance form.
 */
export function promptTrips(context: SpeedContext): readonly Trip[];

/** `Je fietst 6 km in 20 min. Hoe snel is dat?` (suffix km/u) or the distance form (suffix km). */
export function travelQuestion(form: TravelForm, trip: Trip): Question;
export function travelExplanation(form: TravelForm, trip: Trip): string;
export function travelTip(form: TravelForm, trip: Trip): Diagnose;
```

**Ratio table rule (both forms):** for minutes the step is `gcd(60, t)` min, left out when it
equals `t` (t divides 60); for hours the step is `0,5 uur`, left out for whole hours. Rows are
joined with `, ` and written `<time> → <distance> km`. The speed form goes from the given time
to 60 min / 1 uur; the distance form goes from 60 min / 1 uur to the given time.

**Prompts per context:**

| Context  | Speed form                                   | Distance form                                                   |
| -------- | -------------------------------------------- | --------------------------------------------------------------- |
| wandelen | `Je wandelt 3 km in 45 min. Hoe snel is dat?`   | `Je wandelt 5 km/u. Hoeveel km loop je in 45 min?`           |
| fietsen  | `Je fietst 6 km in 20 min. Hoe snel is dat?`    | `Je fietst 18 km/u. Hoeveel km fiets je in 40 min?`          |
| auto     | `Een auto rijdt 60 km in 45 min. Hoe snel is dat?` | `Een auto rijdt 80 km/u. Hoeveel km rijdt de auto in 45 min?` |
| trein    | `Een trein rijdt 300 km in 2,5 uur. Hoe snel is dat?` | `Een trein rijdt 120 km/u. Hoeveel km rijdt de trein in 2,5 uur?` |

**Signatures:**

```ts
/** A trip whose time is the answer: in whole minutes in [5, 59], or in hours from
 * {1,5; 2; 2,5; 3; 4}. The distance is a whole number of km in [1, MAX_DISTANCE]. */
export function timeTrips(context: SpeedContext): readonly Trip[];

/** `Je wandelt 5 km/u. Hoe lang doe je over 2 km?`, suffix the unit of trip.duration. */
export function timeQuestion(trip: Trip): Question;
export function timeExplanation(trip: Trip): string;
export function timeTipFor(trip: Trip): Diagnose;
```

**Ratio table rule:** `<speed> km → 60 min` (or `1 uur`), then the step `g = gcd(speed,
distance)` km, then `<distance> km → <time>`. The step is left out when it equals the first or
last row. A trip is only a candidate when the step time is whole minutes (minute answers) or a
multiple of 0,5 uur (hour answers).

**Prompts:** `Je wandelt 5 km/u. Hoe lang doe je over 2 km?`, `Je fietst 18 km/u. Hoe lang doe
je over 12 km?`, `Een auto rijdt 80 km/u. Hoe lang doet de auto over 60 km?`, the trein as the
auto.

**Test cases — `timeTrips`:**

| ------------------------ | ----------------- | ------------------------- |
| wandelen 5, 2 km         | yes, 24 min       |                           |
| fietsen 24, 10 km        | yes, 25 min       | step 2 km → 5 min         |
| wandelen 6, 1 km         | yes, 10 min       |                           |
| trein 120, 300 km        | yes, 2,5 uur      |                           |
| auto 100, 400 km         | yes, 4 uur        |                           |
| fietsen 16, 2 km         | no                | 7,5 min                   |
| auto 90, 100 km          | no                | 66,67 min                 |
| auto 60, 210 km          | no                | 3,5 uur not in the list   |
| wandelen 6, 30 km        | no                | 30 km > 20                |

**Test cases — answer and explanation:**

| Trip                  | Answer, suffix | Explanation                                             |
