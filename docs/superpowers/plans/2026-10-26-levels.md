# Plan: levels framework (spec §12.2 step 2)

Light plan: files, signatures, test cases. No Verdieping content; every real set keeps the
segment disabled. TDD, one commit per task.

Core idea: `forLevel(set, level)` turns a set into the `PracticeSet` of that level. For `deep`
it swaps `topics` for `set.deep` and sets `tablesPercent: 0`. `buildSession`,
`describeSetTopicRows`, `allocateQuotas` and `generatorsFor` stay unchanged; callers pass the
levelled set.

## Task 1 — model (`lib/types.ts`, `lib/sets.ts`, `lib/setFixture.ts`)

- `types.ts`: `export type Level = 'quick' | 'deep';` and on `PracticeSet`:
  `/** Verdieping topics (spec §12.2); without it the set has Opfrisser only. */ deep?: readonly TopicWeight[];`
- `sets.ts`:
  - `export function hasDeep(set: PracticeSet): boolean` (`deep` present and non-empty; always
    `false` for a `choosesTables` set, so Tafels can never lose its table choice)
  - `export function forLevel(set: PracticeSet, level: Level): PracticeSet`: returns `set`
    itself when `level === 'quick' || !hasDeep(set)` (an empty `deep` would make
    `allocateQuotas` throw)
- `setFixture.ts` (tests only, like `lessons/fixture.ts`): `DEEP_FIXTURE_SET` with
  `id: 'fixture'`, `topics: [{ topic: 'prime', weight: 1 }]`, `tablesPercent: 15` and
  `deep: [{ topic: 'lcm', weight: 2 }, { topic: 'gcd', weight: 1 }]`. Existing topics, so the
  framework needs no new generators, and the prompts tell the level apart (`Is … een
  priemgetal?` or a table versus `KGV van …`/`GGD van …`).

Tests (`sets.test.ts`):

| Input                                   | Expected                                                    |
| --------------------------------------- | ----------------------------------------------------------- |
| `hasDeep` for every `PRACTICE_SETS` set | `false`                                                     |
| `hasDeep(DEEP_FIXTURE_SET)`             | `true`                                                      |
| `hasDeep({ ...set, deep: [] })`         | `false`                                                     |
| `forLevel(set, 'quick')`                | the same object (`toBe`)                                    |
| `forLevel(DEEP_FIXTURE_SET, 'deep')`    | `topics` = the deep list, `tablesPercent` 0, same id/name   |
| `forLevel(NUMBERS_SET, 'deep')`         | the same object (`toBe`; no `deep`: falls back to quick)    |
| `forLevel({ ...fixture, deep: [] }, 'deep')` | `topics` = the quick list (no throw)                   |
| `hasDeep({ ...TABLES_SET, deep: [...] })` | `false`                                                   |
| `describeSetTopicRows(forLevel(fixture, 'deep'), 15)` | `KGV`, `GGD` rows, no `15% tafels` row        |
| `describeSetTopicRows(forLevel(fixture, 'quick'), 15)` | `Priemgetal of niet`, `15% tafels`           |

Tests (`session.test.ts`, `buildSession` with `forLevel(DEEP_FIXTURE_SET, 'deep')`):

| Input  | Expected                                                    |
| ------ | ----------------------------------------------------------- |
| n = 15 | 10 `lcm`, 5 `gcd`, no `tables` (weights 2 : 1, no share)    |
| n = 5  | 3 `lcm` + 2 `gcd` (largest remainder: 3,33 / 1,67)          |

## Task 2 — setup screen (`components/SetupScreen.svelte`)

- New prop `level: Level` (`$bindable('quick')`, so callers without it get Opfrisser;
  `renderSetup` in the test passes it). The topic rows come from
  `describeSetTopicRows(forLevel(set, level), size)`.
- Below **Aantal opgaven**: section heading **Niveau**, a radio group (`aria-labelledby`), 2
  equal segments **Opfrisser** and **Verdieping**, same classes as the count control
  (`.sizes` becomes a shared `.segments` class with the column count as a modifier or inline
  `grid-template-columns`).
- Verdieping: `disabled` when `!hasDeep(set)`. Not rendered for Tafels (`choosesTables`).
- Arrow keys: `onSizeKey` becomes one handler for both groups that filters out disabled
  options before the index step (a disabled Verdieping is skipped, so the arrows do nothing
  there). The new group gets the same `svelte-ignore a11y_interactive_supports_focus` comment.

Tests (`SetupScreen.test.ts`):

| Case                                                  | Expected                                                   |
| ----------------------------------------------------- | ---------------------------------------------------------- |
| a real set (Getallen & delers)                        | Niveau group after the count group; Opfrisser checked; Verdieping `disabled` |
| Tafels                                                | no Niveau group                                            |
| fixture, tap Verdieping                               | Verdieping checked; rows `KGV`, `GGD`, no `15% tafels`     |
| fixture, ArrowRight on Opfrisser                      | Verdieping checked and focused                             |
| real set, ArrowRight on Opfrisser                     | Opfrisser stays checked                                    |
| count arrows still work                               | existing test unchanged                                    |

## Task 3 — app wiring (`App.svelte`)

- `let level = $state<Level>('quick')`; the `PracticeSetList` `onselect` sets `level = 'quick'`
  before showing setup (spec §12.2: every set opens on Opfrisser).
- `SetupScreen ... bind:level`; `startSession` builds with `forLevel(set, level)`, so
  **Opnieuw** reuses the level. The play screen and results get the original `set` (name only).
- New prop `sets?: readonly PracticeSet[]` (default `PRACTICE_SETS`), as `lessons`, so tests
  can use the fixture. Passed to both `PracticeSetList` and `LessonSetList`, which now get
  `PRACTICE_SETS` directly.

Tests (`App.test.ts`, with `sets: [DEEP_FIXTURE_SET]`):

| Case                                                        | Expected                                    |
| ----------------------------------------------------------- | ------------------------------------------- |
| Start without touching Niveau                               | first prompt is not `KGV`/`GGD`             |
| choose Verdieping, Start                                    | first prompt starts with `KGV van` or `GGD van` |
| Verdieping, Start, Stop, Opnieuw                            | first prompt still `KGV`/`GGD`              |
| Verdieping, Terug, open the set again                       | Opfrisser checked                           |
| Verdieping, Start, Stop, Menu, open the set again           | Opfrisser checked                           |
